# Contributing to AB LoRA from URL

Thanks for helping. Three steps:

1. **Open an issue** for anything bigger than a typo, so we can agree on the behaviour before you write code.
2. **Fork, branch, change.** Keep one topic per pull request. A bug fix comes with a test in `tests/` that fails without it.
3. **Run the tests (`pip install -r requirements-dev.txt && pytest`)**, then open the pull request.

Found a bug? An issue with what you did, what you expected and the console output is enough. A workflow JSON helps even more.
